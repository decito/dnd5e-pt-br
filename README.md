## English

### Overview

A community-driven translation for the [Foundry Virtual Tabletop](https://foundryvtt.com/) [Dungeons & Dragons 5th Edition (D&D 5E)](https://foundryvtt.com/packages/dnd5e) system to Brazilian Portuguese. The goal is to provide a comprehensive, accurate, and fully updated translation of all in-game texts and compendium content, adhering to the latest Brazilian Portuguese orthographic standards.

**Note:** Some strings are still from the parent module, resulting in different terms thoughout the documents. For the latest updates and progress on new translations, please consult the status table referenced [at this link](https://github.com/decito/dnd5e-pt-br/blob/main/status.md).

### Installation

#### Method 1: Using the Foundry VTT Module Browser

1. In the Foundry Virtual Tabletop application, click at the `Install Module` button in the "Add-on Modules" section.
2. Search for the `Translation: Português (Brasil) [D&D 5E](SRD)` module in the "Available Modules" list.
   > If you can't find the module, enter the following URL in the "Manifest URL" field: <https://raw.githubusercontent.com/decito/dnd5e-pt-br/refs/heads/main/module.json>
3. Click the "Install" button.
4. After installation, enable the module in your game world settings.
5. Enjoy!

#### Method 2: Manual Installation

1. Download the package from the url <https://github.com/decito/dnd5e-pt-br/releases/latest>.
2. Move the `decito-dnd5e-pt-br` folder from the "modules.zip" file to `Data/modules` directory of your Foundry Virtual Tabletop installation.
3. After installation, enable the module in your game world settings.
4. Enjoy!

## Português

### Visão Geral

Este projeto é uma atualização comunitária do módulo desatualizado de tradução para o português brasileiro do sistema [Dungeons & Dragons 5th Edition (D&D 5E)](https://foundryvtt.com/packages/dnd5e) no [Foundry Virtual Tabletop](https://foundryvtt.com/). O objetivo é fornecer uma tradução completa, precisa e totalmente atualizada de todos os textos do sistema e do conteúdo dos compêndios, em conformidade com as normas mais recentes do novo acordo ortográfico do português brasileiro.

**Nota:** A base dos textos traduzidos foi herdada do antigo pacote de tradução do sistema, o que pode resultar em termos distintos em diferentes partes para a mesma coisa. Para as últimas atualizações e progresso das novas traduções, consulte a tabela de status referenciada [neste link](https://github.com/decito/dnd5e-pt-br/blob/main/status.md).

### Instalação

#### Método 1: Usando o Navegador de Módulos do Foundry VTT

1. No aplicativo Foundry Virtual Tabletop, clique no botão `Instalar Módulo` na seção "Módulos Adicionais".
2. Procure pelo módulo `Translation: Português (Brasil) [D&D 5E](SRD)` na lista de "Módulos Disponíveis".
   > Caso não encontre, insira a seguinte URL no campo "Manifest URL": <https://raw.githubusercontent.com/decito/dnd5e-pt-br/refs/heads/main/module.json>
3. Clique no botão "Instalar".
4. Após a instalação, ative o módulo nas configurações do seu mundo de jogo.
5. Aproveite!

#### Método 2: Instalação Manual

1. Baixe o pacote através do link <https://github.com/decito/dnd5e-pt-br/releases/latest>.
2. Mova a pasta `decito-dnd5e-pt-br` do arquivo "modules.zip" baixado para o diretório `Data/modules` da sua instalação do Foundry Virtual Tabletop.
3. Após a instalação, ative o módulo nas configurações do seu mundo de jogo.
4. Aproveite!
